# 大仕国工 · KUKE 无人装备门户网站

纯静态 H5 企业官网，移动端适配（max-width 480px），展示无人装备产品系列。

## 在线访问

https://676020400yingchun.github.io/kuke-h5/

## 技术栈

- 纯 HTML + CSS + JavaScript，无构建工具
- 响应式移动端设计，适配手机浏览器
- 主题切换：科技蓝·白昼 / 科技蓝·暗夜 / 应急红·白昼 / 应急红·暗夜
- 中英文双语切换

## 功能模块

- **首页**：品牌展示、核心产品亮点、行动入口
- **装备**：全系装备目录，按六大分类筛选
  - 无人车系列（16款）
  - 四足机器人系列
  - 无人机配套系列
  - 反制装备系列
  - 线控底盘系列
- **技术**：核心技术能力展示
- **我的**：企业介绍、理念、联系方式

## 本地开发

```bash
# 克隆仓库
git clone https://github.com/676020400yingchun/kuke-h5.git
cd kuke-h5

# 启动本地预览
python3 -m http.server 8765
```

浏览器打开 http://localhost:8765/

## 部署

GitHub Pages 自动部署，推送到 main 分支即可：

```bash
git add .
git commit -m "update"
git push origin main
```
